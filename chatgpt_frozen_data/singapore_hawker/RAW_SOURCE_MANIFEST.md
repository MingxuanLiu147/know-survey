# Frozen public-source inputs

Core required source:
- NEA Dates of Hawker Centres Closure (2026), data.gov.sg dataset `d_bda4baa634dd1cc7a6c7cad5f19e2d68`.
  The dataset itself contains centre name, closure dates, latitude/longitude, official PHOTOURL, address, stall counts, description and status.
- `nea_hawker_centres_candidates.geojson` is a deterministic five-centre point extract using the official latitude/longitude in that NEA dataset.

Additional provenance snapshots (best effort):
- NEA Hawker Centres GeoJSON dataset `d_4a086da0a5553be1d89383cd90d07ecd`.
- UNESCO Hawker culture in Singapore Representative List page.
- Singapore Tourism Board / VisitSingapore hawker and Chinatown pages plus 52 Weekends guide.
- Official NEA PHOTOURL centre photographs.
