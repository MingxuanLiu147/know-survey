# Inter webfonts

Unmodified Inter Regular (400), Medium (500), and SemiBold (600) WOFF2 files.
Inter is designed by Rasmus Andersson and distributed under the SIL Open Font License 1.1; see [Inter-LICENSE.txt](Inter-LICENSE.txt).

These files were obtained from [OpenBMB/UltraRAG](https://github.com/OpenBMB/UltraRAG/tree/185e2032d9f134099405b8b483edbbad95274080/ui/frontend/public/theme/vendor/fonts/inter) at commit `185e2032d9f134099405b8b483edbbad95274080`. Upstream font project: [rsms/inter](https://github.com/rsms/inter).

The application serves these fonts locally. Chinese glyphs use the system fallback fonts specified in the stylesheet.
